## 3. 演示流程

```text
注册测试账号
→ 登录
→ 创建“研发知识库”
→ 上传 handbook.txt 或 Markdown 文档
→ 等待状态变为 indexed
→ 提问一个文档中确实存在的问题
→ 展示 token 流式回答和 citation
→ 创建故障分析并粘贴日志
→ 展示故障分析流式结果
→ 打开故障历史查看详情
→ 删除测试记录
```

## 5. 简历项目描述草稿

```text
DevAtlas｜研发知识协同平台｜个人项目
技术栈：Vue 3、TypeScript、Element Plus、Pinia、Axios、Python、FastAPI、MySQL、SQLAlchemy、Chroma、BGE Embedding、DeepSeek、JWT、SSE

- 设计并实现面向研发知识管理的多用户知识库平台，完成用户认证、知识库权限隔离、文档上传和版本管理。
- 构建文档解析、文本切分、BGE 向量化、Chroma 检索和 DeepSeek 生成的 RAG 链路，仅允许 indexed 版本参与检索。
- 使用 SSE 实现普通问答和故障分析的流式返回，前端按 token、citation、done、error 事件展示生成过程和来源引用。
- 使用 MySQL 保存用户、知识库、文档版本、文档块、故障分析和引用关系，并实现失败状态保留、重新索引和权限边界。
- 负责前后端联调、异常排查、测试和交付材料整理；使用 AI 编程工具提升开发效率，并对生成代码进行理解、修改、验证和调试。
```

简历中的性能、准确率、响应时间、测试数量等数字必须等 T15 测试完成后填写真实结果，不能先编造。
