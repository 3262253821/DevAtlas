##  遇到的第一个坑

在实现知识库问答 SSE 时，接口能返回 HTTP 200，但流中出现 `LLM_SERVICE_ERROR`。我先确认了端口、Swagger、登录、知识库权限和 RAG 检索都正常，判断问题位于 LLM 流式调用层。进一步发现手写 SSE 解析器把空的 `data` 行当作 JSON 解析，触发了 `json.loads("")`，临时调试代码还因为缩进问题产生了 `UnboundLocalError`。后来改用 OpenAI 兼容客户端解析 DeepSeek 的流式响应，由客户端处理 SSE 边界和事件格式，后端只提取 `delta.content`，最终解决了问题。
