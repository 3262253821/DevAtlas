## 任务分组

- T06-T09：文件上传、解析、版本、向量入库和文档管理；

## 不能丢失的开发顺序

```text
基础初始化 → 配置 → 数据库 → 认证 → 知识库权限
→ 文件上传 → 解析切分 → Embedding/Chroma
→ 文档管理 → RAG 检索 → DeepSeek
→ 问答 SSE → 故障分析 → Vue 联调 → 测试交付
```

## 不能丢失的开发方式

- 用户自己创建文件、执行命令和测试；
- AI 提供小步代码和解释，不一次生成整套不理解的代码；
- 每项任务完成“运行、解释、测试、小修改”闭环；
- 一个可验证功能完成并测试通过后再提交 Git；
- 后端主链路优先于页面装饰、问答历史、完整版本页面和 Redis；
- 不因为设计文档冻结就假设实现阶段不会出错，真实错误按代码、契约、迁移、依赖和需求变化分类处理。
