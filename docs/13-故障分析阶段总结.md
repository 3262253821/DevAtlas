## 数据表

### incidents

保存故障分析业务记录：

- 故障标题和原始日志；
- 所属用户和知识库；
- `streaming/completed/failed/cancelled` 状态；
- AI 分析结果；
- 错误信息、模型名称和时间。

### incident_citations

保存故障分析引用的 `document_chunk_id` 和引用序号，与 `incidents` 建立一对多关系。

## 接口

```text
POST /api/v1/knowledge-bases/{knowledge_base_id}/incidents/stream
GET /api/v1/incidents
GET /api/v1/incidents/{incident_id}
DELETE /api/v1/incidents/{incident_id}
```

## 完整调用链

```text
故障标题 + 日志
→ 鉴权
→ 校验知识库 owner_id
→ 创建 incidents(status=streaming)
→ T10 retrieve_context()
→ build_incident_messages()
→ T12 stream_chat_with_llm()
→ 发送 token 事件
→ 保存分析结果和 incident_citations
→ 发送 citation 事件
→ 更新 incidents(status=completed)
→ 发送 done 事件
```

## 状态流转

```text
streaming
├── 正常生成完成 → completed
├── DeepSeek/处理失败 → failed
└── 客户端中断 → cancelled
```

只有正常完成时才保存分析结果并写入引用。失败状态保留错误信息，便于历史查询和排查。

## 权限设计

- 创建前校验当前用户拥有目标知识库；
- incident 列表只查询当前用户的记录；
- 详情和删除同时校验 `incident_id + owner_id`；
- 其他用户无法通过修改 ID 读取或删除记录，统一返回 `404`。

## 验证结果

- Alembic 成功创建 `incidents` 和 `incident_citations`；
- 合法故障请求返回 `token → citation → done`；
- `done` 事件包含 `incident_id` 和 `status=completed`；
- `GET /api/v1/incidents` 能查询历史记录；
- `GET /api/v1/incidents/{incident_id}` 能返回输入、结果、状态和 citations；
- `DELETE /api/v1/incidents/{incident_id}` 返回 `204`，删除后详情返回 `404`；
- 未登录返回 `401`；跨用户知识库返回 `404`；非法参数返回 `422`。
