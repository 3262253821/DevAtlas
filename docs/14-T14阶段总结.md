# T14 前端页面和前后端联调阶段总结

## 阶段目标

在浏览器中跑通 DevAtlas MVP 主链路，并让前端统一处理路由、JWT、Axios 请求和 SSE 流式响应。

## 已完成内容

- T14-A：安装 `vue-router`，配置 Axios、Pinia、JWT 持久化、路由守卫和 FastAPI CORS；
- T14-B：完成登录和注册页面，接入 `/api/v1/auth/login`、`/register`；
- T14-C：完成知识库列表、创建、删除和知识库工作台；
- T14-D：完成 TXT/Markdown/PDF 上传、文档状态展示、删除和失败版本重新索引；
- T14-E：完成普通问答 SSE、引用展示、故障分析 SSE、历史查询、详情和删除；
- T14-F：完成全局导航、退出登录、失效 Token 跳转、响应式样式和完整浏览器验收。

## 前端关键目录

```text
frontend/src/api       Axios、业务接口和 SSE 解析
frontend/src/router    页面路由和鉴权守卫
frontend/src/stores    Pinia 登录状态
frontend/src/views     登录、知识库、文档、问答和故障页面
```

## 浏览器主链路

```text
注册 → 登录 → 保存 JWT
→ 创建知识库 → 上传文档 → 后端解析/Embedding/Chroma → indexed
→ 普通问答 SSE（token/citation/done）
→ 故障分析 SSE → incidents 历史查询 → 删除
```

## 关键设计

- 普通 JSON 接口统一通过 Axios 请求，由请求拦截器自动添加 `Authorization: Bearer`；
- SSE 不使用 Axios 的 JSON 解析，使用 `fetch`、`ReadableStream` 和 `TextDecoder` 按空行解析事件块；
- `token` 事件拼接回答，`citation` 事件保存引用，`done` 事件结束流，`error` 事件展示失败原因；
- 前端路由只保护需要登录的页面，未登录访问会跳转 `/login`；
- 后端仍然负责最终权限校验，前端路由守卫不能替代后端权限控制。
