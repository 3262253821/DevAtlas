# T14 前端页面和前后端联调规划

## 当前前端状态

当前 `frontend/src` 仍是 Vite 默认脚手架，依赖已有：

- Vue 3；
- TypeScript；
- Element Plus；
- Pinia；
- Axios。

尚未安装 `vue-router`，也还没有完成 API 封装、登录态管理和页面路由。

## T14 目标

完成浏览器中的 MVP 主流程：

```text
注册 → 登录 → 创建知识库 → 上传文档 → 等待 indexed
→ 知识库问答 SSE → 故障分析 SSE → 查看历史记录
```

## 推进顺序

### T14-A：前端基础设施

交付物：

- `vue-router` 路由；
- Axios API 实例；
- `VITE_API_BASE_URL` 配置；
- Pinia 登录状态；
- JWT 保存、读取、清除；
- Axios Bearer 请求头；
- 路由守卫；
- 后端 CORS；
- 前端访问 `/health` 验证。

原因：没有统一的路由、请求和认证层，后续每个页面都会重复处理 Token 和错误。

### T14-B：登录注册

页面：

- `/login`；
- `/register`。

验收：注册成功跳转登录，登录成功保存 Token 并进入知识库列表，退出后受保护页面不可访问。

### T14-C：知识库

页面：

- `/workspaces`；
- `/knowledge/:id`。

功能：查询、创建、删除知识库，进入工作台。

### T14-D：文档管理

页面：

- `/knowledge/:id/documents`。

功能：上传 TXT/Markdown/PDF，显示 `pending/indexed/failed`，查看错误，删除和重新索引。

### T14-E：问答和故障分析

页面：

- `/knowledge/:id/qa`；
- `/knowledge/:id/incidents/new`；
- `/incidents`。

功能：解析 SSE `token/citation/done/error`，连续拼接回答，展示引用，提交故障分析，查询和删除历史记录。

### T14-F：整体验收

验证登录、权限、上传、索引状态、普通问答 SSE、故障分析 SSE、历史查询和异常状态。

## 关键联调问题

- 前端 `5173` 访问后端 `8001` 需要 CORS；
- Axios 统一处理 `401` 并清除登录态；
- SSE 不使用普通 Axios JSON 解析，要逐事件读取并按 `event` 分发；
- `token` 事件按顺序追加，`citation` 事件单独保存，`done` 结束请求；
- 用户主动中断时需要取消请求并把页面状态恢复为可再次提交；
- 只展示当前用户有权限的知识库和 incident。

## MVP 取舍

第一版优先可用和可验证，不先做：

- 问答历史会话；
- 复杂权限角色；
- 多主题和高级视觉动效；
- Agent、Reranker、BM25、RRF；
- Docker 部署和 Redis 优化。
