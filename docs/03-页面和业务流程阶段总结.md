## 不能丢失的业务流程

### 文档入库

上传 → 权限校验 → 文件哈希 → 重复判断 → 创建版本 pending → 解析 → 切分 → Embedding → Chroma → indexed；失败则记录 failed、错误原因并清理半成品。

### 知识库问答

选择知识库 → 权限校验 → 只检索 indexed 文档块 → 组装上下文 → 调用 LLM → SSE 返回 token/citation/done → 展示答案和来源。

### 故障分析

填写标题和日志 → 选择知识库 → 权限校验 → 检索技术文档 → 调用 LLM → SSE 返回 → 成功后保存故障分析记录。

## 阶段 4 前置确认

技术选型涉及本机环境，不能从聊天记录猜测。进入阶段 4 设计前必须确认：

- MySQL 或 SQLite，以及已安装版本；
- Python、Node.js、Docker 版本和可用性；
- LLM 提供商；
- Embedding 使用本地模型还是云端 API；
- 前端 UI 库；
- 是否需要 GitHub/Gitee 仓库。
